# 樂佩的魔法世界 V2.4

一個適合手機、平板與桌面瀏覽器的小型點擊遊戲。玩家可以選擇氣球、水果、動物園或車車模式，在 30 秒內點擊掉落的物件、累積星星、保持連擊並聽到對應音效。

## V2.4 改善

- 壓縮手機首頁面板，讓模式、設定、獎章、排行榜與商店在首屏內完整呈現。
- 強化場景背景的層次：遠山、雲、陽光、柵欄、果園樹木、動物園入口與交通道路。
- 保留明亮童話動畫風格，避免使用特定品牌畫風。

## V2.3 改善

- 新增幼兒/大童年齡模式。幼兒版更慢且 HUD 只顯示星星，大童版保留時間、連擊、關卡與任務挑戰。
- 新增獎章系統：10、30、50 星解鎖天燈、皇冠與魔法塔。
- 新增魔法幣與輔助道具商店：慢慢粉、星星磁鐵、幸運皇冠。
- 新增語音鼓勵，點擊成功時會用瀏覽器語音播放「好棒！」等鼓勵。
- 新增模式任務，依模式指定要收集的水果、動物、車車或氣球。
- 新增 localStorage 本機排行榜與最高分保存。
- 新增不同模式的明亮童話動畫風背景：果園、動物園、交通道路與天空氣球。

## V2.2 改善

- 新增輕鬆、標準、挑戰三段難度設定。
- 不同難度會調整時間長度、生成速度、掉落速度與升關門檻。
- 新增程式合成背景音樂，不需要額外音檔或外部連結。
- 背景音樂可單獨開關，靜音按鈕仍可一鍵關閉所有聲音。

## V2.1 改善

- 30 秒挑戰、關卡加速與 combo 分數。
- 暫停、重新開始、靜音、回選單控制。
- 更友善的星星/時間/連擊/關卡/飄走統計。
- 樂佩主題的塔樓、金髮與天燈背景。
- 統一觸控/滑鼠事件，並修正點擊特效的位置。
- 加入音量總控與音效資源快取。

## GitHub Pages

這個專案是純前端單頁遊戲，入口檔是 `index.html`。啟用 GitHub Pages 後可直接從 repository root 發佈。

## 本機開啟

直接用瀏覽器開啟 `index.html` 即可遊玩。
