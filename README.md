# 樂佩的魔法世界 V3.0

一個適合手機、平板與桌面瀏覽器的小型點擊遊戲。玩家可以進入十關冒險，或選擇氣球、水果、動物園、車車、英文字母模式進行限時挑戰，點擊掉落的物件、累積星星、保持連擊並聽到對應音效。

## V3.0 改善

- 新增英文字母模式，A-Z 會以字母卡掉落。
- 每個英文字母都對應一個英文單字，點擊消失時會播放該單字的英語發音。
- 冒險闖關加入英文字母關卡，並更新離線快取版本。

## V2.7 改善

- 任務目標改成物件圖示顯示，不再用文字標示要點哪一個物件。
- 幼兒模式也會顯示任務目標圖示與收集進度。
- 交通工具掉落物改用較寬的顯示框，改善車子、火箭、腳踏車看起來被裁切的問題。

## V2.6 改善

- 使用 Image Generation 技能繪製新的掉落物圖像，替換原本的純色氣球與 emoji 掉落物。
- 新增 16 種較精緻的 3D 玩具風物件：氣球、水果、動物與交通工具。
- 掉落物加入分類動畫效果：氣球飄動、水果搖晃、動物呼吸、車車微幅行進。

## V2.5 改善

- 新增首頁「冒險闖關」入口，十個關卡會依序切換氣球、水果、動物與車車場景。
- 冒險模式不再受 30 秒挑戰限制，改用每關任務目標推進，難度透過關卡、目標數、生成速度與掉落速度逐步提高。
- 任務目標在冒險與挑戰中會更穩定地出現，避免玩家被隨機卡關。
- 背景音樂改用 `assets/audio/where-the-sunbeams-hide.mp3`，並保留音樂開關與全域靜音控制。

## V2.4 改善

- 壓縮手機首頁面板，讓模式、設定、獎章、排行榜與商店在首屏內完整呈現。
- 強化場景背景的層次：遠山、雲、陽光、柵欄、果園樹木、動物園入口與交通道路。
- 保留明亮童話動畫風格，避免使用特定品牌畫風。

## V2.3 改善

- 新增幼兒/大童年齡模式。幼兒版更慢且 HUD 只顯示星星，大童版保留時間、連擊、關卡與任務挑戰。
- 新增獎章系統：10、30、50 星解鎖天燈、皇冠與魔法塔。
- 新增魔法幣與輔助道具商店：慢慢粉、星星磁鐵、幸運皇冠。
- 新增語音鼓勵，點擊成功時會用瀏覽器語音播放「好棒！」等鼓勵。
- 新增模式任務，依模式指定要收集的水果、動物、車車或氣球。
- 新增 localStorage 本機排行榜與最高分保存。
- 新增不同模式的明亮童話動畫風背景：果園、動物園、交通道路與天空氣球。

## V2.2 改善

- 新增輕鬆、標準、挑戰三段難度設定。
- 不同難度會調整時間長度、生成速度、掉落速度與升關門檻。
- 新增程式合成背景音樂，不需要額外音檔或外部連結。
- 背景音樂可單獨開關，靜音按鈕仍可一鍵關閉所有聲音。

## V2.1 改善

- 30 秒挑戰、關卡加速與 combo 分數。
- 暫停、重新開始、靜音、回選單控制。
- 更友善的星星/時間/連擊/關卡/飄走統計。
- 樂佩主題的塔樓、金髮與天燈背景。
- 統一觸控/滑鼠事件，並修正點擊特效的位置。
- 加入音量總控與音效資源快取。

## GitHub Pages

這個專案是純前端單頁遊戲，入口檔是 `index.html`。啟用 GitHub Pages 後可直接從 repository root 發佈。

## 本機開啟

直接用瀏覽器開啟 `index.html` 即可遊玩。
